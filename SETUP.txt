SURVEY FLOW | WINDOWS QA CONSOLE
================================

1. Extract SurveyFlow-Recovery-Console to a writable folder.
2. Double-click SurveyFlow.exe (Windows 10+ recommended).
3. Paste the URL of an AUTHORIZED QA / TEST survey.
   If the URL has no test marker, type TEST only when the link
   has been independently approved for survey QA. Never use live fielding.
4. Enter the number of confirmed QA qualifications required (1-50).
5. Follow the console status and review results in:
     reports\\run-report.json
     reports\\batch-report.json
     data\\launcher.log
   Previous runs and batches have unique archived JSON names.
6. The console stops on unresolved mandatory questions, unverified
   redirects, corrupt saved memory or unsaved QA evidence.

OPTIONAL: config\\app.json includes "replayVerifiedSets": false.
Enable only for exact reproduction of an already verified multi-select
QA answer path; leaving it false preserves answer variety.

A successful test completion requires Qual.html on the original survey
origin. Third-party redirects remain unverified without approved support.

The release contains no universal ranking/hotspot solver, CAPTCHA
bypass, or support guarantee for every survey's custom widgets.

FOR DEVELOPERS: inspect README.md, QUESTION_TYPES.md and QA_REPORT.md.
